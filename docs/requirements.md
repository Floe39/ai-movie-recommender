# 已实现功能清单

| 功能 | 当前实现 |
| --- | --- |
| 条件找片 | 解析类型、时长、年份、评分等条件，用 TMDB 查询并复核详情字段 |
| 故事描述找片 | 用少量真实影片简介和百炼 Embedding 进行语义匹配 |
| 真实影片详情 | 标题、海报、简介、时长、类型、评分与 TMDB 链接均来自 TMDB |
| 推荐理由 | 大模型只根据已验证的候选字段生成中文理由 |
| 今日推荐 | 每天生成一次 5 部高分电影，当天从 SQLite 缓存读取 |
| 片单 | 想看、已看、短评与删除操作持久化到 SQLite |
| 推荐历史 | 保存本次需求、结构化条件与结果电影 ID |
| 影片简介库 | 从 TMDB 导入少量真实简介，供故事描述检索使用 |
| 异常处理 | 对模型、TMDB、Embedding 与请求校验返回统一错误信息 |

## 边界

- 当前为匿名单用户演示项目；
- 不提供视频播放、购票、支付或账号系统；
- 不提供多轮聊天、反馈训练、MCP 服务或用户自建资料库；
- 电影事实由 TMDB 提供，大模型不会自行编造影片字段。
